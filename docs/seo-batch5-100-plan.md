# SEO Content Batch 5: 100 Articles (2026-07-10)

Fifth batch, 100 fresh articles for browserbash.com. Blog was at 741 posts. Spec: `tools/seo/specs-batch5-100.json` (zero slug collisions with existing 741, verified programmatically).

## Generation

Planned as Codex + Opus 4.8 split, but **Codex was blocked**: local `codex-cli` 0.134.0 is too old for the ChatGPT account's only allowed model (`gpt-5.6-sol` returns "requires a newer version of Codex"), and every older model (`gpt-5-codex`, `gpt-5.1`, etc.) returns "not supported when using Codex with a ChatGPT account". Fix for next time: `brew upgrade codex` (or `npm i -g @openai/codex`) then re-run.

So all 100 were generated by **Opus 4.8 agents**, one agent per article, via a background Workflow (`seo-batch5-100`). Each agent reads a shared preamble (FACTS + RULES lifted from `tools/seo/write-articles-v150-50.workflow.js`, current for v1.5.1) plus its spec, writes directly to `site/content/blog/<slug>.md`, and self-checks em-dash count, FAQ count, and word count before returning a receipt.
